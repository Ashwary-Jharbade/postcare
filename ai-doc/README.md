# `ai-doc/` — AI-oriented project context

**If you are an AI agent:** read this folder when you need a **compact, project-wide picture** before planning or implementing work. Prefer **`PROJECT_CONTEXT.md`** (when present) over opening every ticket under `ai-dev/`.

## Purpose

- **Rollup context:** This directory holds documentation meant to be **token-efficient**—one hierarchical view of what the product does, how features relate, and where work tends to land in the repo.
- **Not a substitute for `ai-dev/`:** Day-to-day ticket artefacts (`plan.md`, `control.md`, `development.md`, etc.) still live under **`ai-dev/<ticket-number>/`** per the project pipeline. `ai-doc/` is for **cross-ticket synthesis** and optional mirrored narrative docs.

## Files and layout

| Path | Role |
|------|------|
| **`PROJECT_CONTEXT.md`** | Generated by the **`/reldoc`** command. Consolidates per-ticket `documentation.md` sources (from `ai-doc/` and, when needed, `ai-dev/`) into a single hierarchy for fast orientation. **Regenerate after major ticket merges** if you rely on it. |
| **`README.md`** | This file—explains the folder for humans and agents. |
| **`/<ticket-number>/documentation.md`** *(optional)* | Per-ticket layperson docs **mirrored or authored here** if the team wants rollup sources to live under `ai-doc` only. The Document Agent (`/document`) writes to `ai-dev/` by default; copy or sync here if your process prefers `ai-doc` as the canonical doc tree for `/reldoc`. |

## When to use what

- **Starting a new feature:** Read `PROJECT_CONTEXT.md` first (if it exists), then open the relevant ticket folder under `ai-dev/` for the live plan and control board.
- **Refreshing the rollup:** Run **`/reldoc`** so `PROJECT_CONTEXT.md` stays aligned with ticket documentation.

## Relationship to `ai-dev/`

- **`ai-dev/`** — authoritative **per-ticket** pipeline workspace.
- **`ai-doc/`** — **project-level** context for agents (especially `PROJECT_CONTEXT.md`), plus optional per-ticket docs under `ai-doc/<ticket>/`.

If `PROJECT_CONTEXT.md` is missing or stale, say so and use `AGENTS.md`, `README.md`, and the relevant `ai-dev/<ticket>/` files instead.
