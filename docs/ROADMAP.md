# Roadmap

## Milestone 1: Foundation
- Finalize stack and package approval checklist
- Scaffold frontend app and project config
- Add PWA shell, linting, type-checking, tests, and security tooling
- Establish ADRs, templates, and contributor workflow

## Milestone 2: Core Request Flows
- Build request composer with methods, headers, params, and body editors
- Add auth support and environment variables
- Persist requests, collections, and history locally
- Add response viewer and request code generation

## Milestone 3: Analysis
- Add response comparison across environments
- Add diff views, request timing, and tracing
- Add simulation for delays, failures, and edge cases

## Milestone 4: AI Workflows
- Add edge-case generation
- Add response error explanation
- Add request improvement suggestions with strict redaction and review steps

## Milestone 5: Hardening
- Improve accessibility and offline coverage
- Add migration and regression tests
- Complete security review and performance tuning
